# DLC + J-turn 联合工况：R70 建路参数

三个手动 CarSim Run 应共用同一条道路。DLC 用直路上的锥桶表示；双移线是**控制器内部参考轨迹**，不必把它画进 CarSim 道路中心线。起点 `(X,Y)=(0,0) m`，初始航向 `0°`，起始 station `0 m`。

| 路段 | 几何 | 终点 `(X,Y)` | 结束 station |
|---|---|---|---:|
| DLC 摆锥桶区 | 直路 X=0–200 m，控制器参考轨迹双移线 | `(200,0)` | `200.000 m` |
| 中间直线 | 长度 80 m | `(280,0)` | `280.000 m` |
| J-turn | **左转 90°、半径 70 m**，不是 180° U-turn | `(350,70)` | `389.956 m` |
| 出弯直线 | 长度 100 m，航向 90° | `(350,170)` | `489.956 m` |

手动建路时，在 **Path: Segment Builder** 中填 `straight 280 m`、`radius 70 m / 90 deg`、`straight 100 m` 即可；锥桶只标示 DLC 路段，控制器仍从 `func_WayPoints(6,70,false)` 读取双移线参考轨迹。先前导出的 [R70 X–Y–station 坐标表](../results_combined/combined_path_r70_xy_station.csv) 属于自动生成的另一版 CarSim 道路，手动摆锥桶时**不需要导入**，两版道路的 station 相差约 0.64 m，不要混用其摩擦切换 station。

在同一条直线的 station `230 m`（X=230 m），路面摩擦系数从
`μ=0.5` 切换为 `μ=0.85`；弯道还要再往前 50 m 才开始。
三个 Run 初速度同为 90 km/h，控制器在 DLC 后的直线段把目标车速
平滑调到 80 km/h。独立 J-turn 道路不受此联合工况设置影响。

三个手动 Run 请分别命名为：

- `COMB90_DLC05_JT_R70_mu0.5to0.85_MPC`
- `COMB90_DLC05_JT_R70_mu0.5to0.85_ZENG`
- `COMB90_DLC05_JT_R70_mu0.5to0.85_PMPC`

名称很重要：控制器按 CarSim Run 名识别联合路径、半径和摩擦切换；
现有 `DLC_Jtuin_80_...` 名称会被当作普通 DLC。
三份 Run 分别选择 `mpc_mil.slx`、`zeng_mil.slx`、`pmpc_mil.slx`，
分别 **Send to Simulink** 后再手动运行。

R70 仅作为对照试验：2026-10-02 的仿真中，三个控制器在 J-turn 段均有
角点越界，不能将它作为“全程不越界”的最终论文工况。
