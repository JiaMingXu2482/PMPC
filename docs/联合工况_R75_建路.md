# DLC + J-turn 联合工况：CarSim 建路参数（R75）

三个 Run（MPC、ZENG、PMPC）应引用**同一条道路中心线、同一张路面附着图**。
道路从 `(X,Y)=(0,0) m` 出发，初始航向 `0°`，起始 station 为 `0 m`。

| 段 | 几何 | 全局坐标范围 | 结束 station |
|---|---|---|---:|
| 1 | 平滑 DLC 双移线，向左移约 3.556 m 后回到原车道 | `X=0–200 m`，终点 `(200,0)` | `200.645 m` |
| 2 | 直线，长度 `80 m`；`X=230 m` 处切换路面附着 | `(200,0) → (280,0)` | `280.645 m` |
| 3 | **左转 90°，半径 75 m**，不是 180° U-turn | `(280,0) → (355,75)` | `398.455 m` |
| 4 | 出弯直线，长度 `100 m`，航向 `90°` | `(355,75) → (355,175)` | `498.455 m` |

第一段的中心线不是一串常半径圆弧。与控制器一致的表达式为

`Y(X)=3.5564696255/2·[1+tanh(4/27.8522027852·(X−80.0586890405))]−3.5564696255/2·[1+tanh(4/24.0077954233·(X−132.3569874089))]`，
`0≤X≤200 m`。请用项目生成的 [R75 X-Y-station 坐标表](../data/combined_path_r75_xy_station.csv)建立 CarSim 的
**Path: X-Y Coordinates** 数据集；每行依次为 `X (m), Y (m), station (m)`，无表头。
该表由 `func_WayPoints(6,75,false)` 导出，DLC 每约 `2 m` 一个点，圆弧每约 `2 m` 一个点。
不要把截图中原有的 `straight 180 m + radius 80 m / 180° + straight 180 m`
当作此工况：它既没有 DLC，也把 90° J-turn 变成了 180° U-turn。

路面摩擦按 **station** 分段：`0–230.645 m` 为 `μ=0.5`，其后为 `μ=0.85`。
切换点位于第二段直线上，弯道开始前还留有 `50 m`。
三个 Run 的初速度同设 `90 km/h`，目标速度在 DLC 后的直线段从 `90`
平滑降到 `80 km/h`；在这条联合路径中控制器从 `X=230 m` 起也使用 `μ=0.85`。
独立 J-turn 道路不受此文件影响。

操作时先在 CarSim 建一份 X-Y Coordinates 路径和一份分段摩擦路面，
再让三个 Run 均引用它们；分别选择 `mpc_mil.slx`、`zeng_mil.slx`、
`pmpc_mil.slx`。若仍使用 Path: Segment Builder，单靠
`straight/radius` 行无法与当前控制器参考 DLC 精确一致。

手动用 `run_current_carsim(...)` 跑时，请将现有三个 Run **重命名**为
`COMB90_DLC05_JT_R75_mu0.5to0.85_MPC`、
`COMB90_DLC05_JT_R75_mu0.5to0.85_ZENG`、
`COMB90_DLC05_JT_R75_mu0.5to0.85_PMPC`。
当前控制器按 Run 名识别联合工况及半径；截图中的 `DLC_Jtuin_80_...`
会被识别成普通 DLC，无法使用 R75 参考线，也不会在直线段切换控制器内部的 µ。
重命名、设好道路与模型后，对每个 Run 分别点击 **Send to Simulink**，
再调用对应的 `run_current_carsim('mpc_mil')` 等命令。
