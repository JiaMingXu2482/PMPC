# 项目目标

## 目标

围绕车辆多执行器协调控制，写一篇论文。

执行器：AFS（主动前轮转向）、DYC（直接横摆力矩，通过差动制动实现）、CDC（连续可调阻尼半主动悬架）。

## 创新点方向

围绕**优先级策略**做创新点。"优先级"可以自行定义，不限于字典序/固定权重，包括但不限于：按稳定性裕度自适应调节的权重、按执行器能力包络动态调配的优先级、随预测状态演化的能力集合约束等。

## 要求

1. **创新性**：策略机制要有新意，能与现有文献（固定权重 MPC、静态优先级、字典序 QP 等）区分开，有明确的、能写进论文的机制陈述。
2. **鲁棒性**：策略必须在多个工况下都有效果（FishHook、Slalom、DLC 等），只在单一工况上有效不算数；对参数/工况变化不敏感，不依赖针对单一工况的调参。

## 现状（2026-11-18）

- PMPC 三执行器协调框架已有（Simulink + CarSim MIL）。
- 时滞补偿方向已证伪：τ_d = 1e-4 与 12.7 ms 在全部步长下闭环 LTR 几乎相同。
- Route A（能力集合随预测状态演化 Ω_{k+j}(φ̇_{k+j})）正在验证中，主验证工况 FishHook 80。
- 两参数权重调度（横摆裕度 + 侧倾裕度驱动）是候选方向，尚未实现验证。
