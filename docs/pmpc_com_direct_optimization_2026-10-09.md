# PMPC COM 直接优化记录（2026-10-09）

跳过“允许 DB / 禁止 DB”的离线诊断，直接完成五次 COM 闭环候选试验。
每次均运行到 19.999 s。使用相同 R=75 m、入弯 X=330 m 的 Run_all.par；
名称中的 R70 是旧名称，不代表实际半径。没有新增纵向限速或 Vx 状态。

## 保留配置

- Atuning_pmpc：R1=100（原 10），V2=8000（原 80000）；其余调参未改。
- PMPC 的 Ncons_sh=Ncons_r=Np=10；Nc=5、Ts=0.1 s、first_Tc=0。
- PMPC 求解前精确消去六个固定为零的无用松弛变量、两个固定为一的 gamma。
- PMPC 专用 KWIK 路径：约束行归一化并恢复原尺度乘子；失败的热启动仅重试一次冷启动，不沿用失败活动集。
- 不改变现有道路边界、优先级权重规则和上限，不给执行器排序。
- MPC、ZENG、PMPC_nodelay 的参数和求解路径未在本轮改变。SLX 无需修改。

本轮是数值实现与第三层代价的优化，不是新的预测风险理论或严格优先级证明。
约束缩放的解析最优解与 KKT 乘子恢复检查通过；五次闭环运行完成。

## 控制诊断及限制

诊断窗口沿用脚本 t<=8 s 与 t>=12.5 s，不等同于精确道路分段。
方向盘指令相邻采样增量 RMS：前段 2.6276 -> 2.1319 deg，后段 1.8008 -> 1.5516 deg。
这是指令平滑度改善，不表示实际前轮转角抖动已完全解决。

后段 abs(Mb)>50 Nm 的比例 72.4% -> 66.0%，不能声称“更多或更早 DB”已得到证明。
后段求解 exitflag~=1 比例仍为 13.8667%；本轮未消除求解非成功问题。
J-turn 跟踪仍明显弱于用户此前 ZENG 结果，不能宣称已达到历史纵向限速版本的效果。
两个 V2=800 的候选虽然 J-turn 更好，但 DLC 明显恶化，因此不采用。

## 手动重跑

若此前工作区有调参覆盖值，先清除这三个试验覆盖变量，使配置文件生效：

```matlab
clear PMPC_R1 PMPC_V2 PMPC_FIRSTTC
run_current_carsim('pmpc_mil');
```

继续使用同一 COM Send。不要将此 COM 调参结果当作 Slalom 已通过验证。
