# baseline 固定阻尼修复：Slalom LTR→1.0 的追查

## 0. 结论先说

1. **修复的代码路径是干净的**：把 `md_frozen_on` 设为 false（退回"不含被动阻尼力矩"）
   后，新代码逐项复现 v3：`ey 0.834 / roll 4.12° / SW 139.6 / LTR 0.828`
   （v3 是 `0.8336 / 4.12 / 138.4 / 0.828`）。
2. **符号链自洽**（用运行数据验证，不是靠推导）：
   - `corr(φ, LTR) = −0.96` → φ>0（向右滚）对应 LTR<0（右侧加载）
   - `corr(Md, p) = +0.975` → 实测被动力矩与侧倾角速度同相，即它是**阻尼**力矩
   - 因此 `p_dot += −Md/Ix` 是阻尼项、`LTR += +k·Md` 是减少 |LTR| 的项，二者不矛盾
3. **但闭环结果反直觉**：加上这个阻尼项后，baseline 在 Slalom 上
   `LTR 0.828 → 1.000`、`SW 138.4 → 191.6`、`ey_max 0.834 → 0.892`。
   **我没有找到能自洽解释它的机制**，按审查要求不猜，标为未解决。

## 2. LTR=1.000 的含义

`pmpc_base_step` 的 LTR 由四轮 Fz 计算：`(FzL1+FzL2−FzR1−FzR2)/ΣFz`。
**达到 1.000 表示右侧两轮 Fz 同时卸载到 0/负值（离地），不是翻车。**
fair 运行有 28 个样本 >0.9，集中在 t≈3.55 s 与 5.57–5.60 s；roll 只有 4.49°。
v3 在同样时刻是 0.828（未离地）。

## 3. 为什么"加阻尼反而更差"——未解决

可能的解释（都未经证实，不作为结论）：

- (a) baseline 只有 AFS + 差动制动，模型里多出一个**它无法控制**的力矩项后，
  QP 的可行域/活动集被改变，松弛变量的分配随之变化，导致动作变大；
- (b) LTR 的仿射右端一次性平移了 `k·Md`（本次 Md rms ≈ 1701 N·m，`k·Md ≈ 0.12`，
  相当于 0.12 个 LTR 单位，约 15% 的约束余量），使 LTR 约束在关键时刻**提前/滞后**触发；
- (c) 该项在预测域内被冻结为常数（不随预测步变化），而真实 Md 会随 p 变化，
  冻结近似在预测时域末端误差很大（1 s 内 p 可以反号）。

**需要用更细的诊断（例如逐拍对比预测 p 与实测 p、或把 Md 冻结项换成随 p 的阻尼系数）
才能区分。本轮不做。**

## 4. 对对比的影响与建议

- 修复后的 baseline 是**物理上更正确**的对照；
- 但它在 Slalom 上出现的 `LTR=1.0`（离地）使这一组对比在 Slalom 上失去解释力；
- 在此之前，Slalom 的四格对比只能说明"noComp/Comp 相对**修复前**的 baseline 更好"，
  不能用修复后的 baseline 做严格对照。

建议二选一（需要审查确认，我不自行决定）：

1. **保留修复**，但把 Slalom 的 baseline 结论限定为"该工况下 baseline 出现内侧车轮离地"，
   并补一段诊断说明冻结近似的局限；
2. **暂时回退到 v3 口径**（`md_frozen_on=false`）作为主对照，把修复版作为附录，
   并明确写"baseline 的被动阻尼力矩未建模"这一已知失配。
