## 2. baseline 固定阻尼修复

**问题**：baseline 用固定 1 A，但预测模型里完全不含被动阻尼力矩 ——
`pmpc_base_predict.m` 的侧倾方程无阻尼项、`pmpc_base_prepare.m` 的 LTR 映射不含 Md。

**最小修复**（保持 2 控制量 / 6 状态，不把 Md 变成可优化输入）：

| 文件 | 改动 |
|---|---|
| `pmpc_base_init.m` | 新增 `V.ldf = V.ldr = 1.1`（与 Proposed 一致） |
| `pmpc_base_prepare.m` | `Bd = .5*[-ldf;-ldr;ldf;ldr]`；`MdFrozen = Bd'*meas.Fd`；`MdLTR = kL*MdFrozen`；两者放进 `c` |
| `pmpc_base_predict.m` | 扰动由 3 列扩到 **4 列**，第 4 列 `[0;0;0;-1/V.Ix;0;0]`，与 Proposed 的 `B(4,3)=-1/Ix` 同号；`expm` 的底部块相应改为 `zeros(6,12)`（12×12） |
| `pmpc_base_step.m` | LTR 约束右端扣除 `c.MdLTR`，**只扣一次** |

**检查**（`check_md_fix.m`，不跑仿真）：

```
A) Md=0 与旧实现（局部复制的 3 扰动版本）最大差 = 1.388e-16  → PASS
B) Md=+1000 的 p 增量 首/末 = -0.0834 / -0.1079；1 ms RK4 独立对照同为
   -0.0834 / -0.1079，误差 2.70e-11；Md=-1000 对称误差同量级 → PASS
C) LTR 仿射项变化 = -0.707558 = -kL*Md/EPS（恰一次）           → PASS
```

**限制（必须随结果一起引用）**：这是"实测 Md 冻结在预测域"的近似，
没有预测固定电流下未来阻尼力的变化；不是 robust/被动性的证明。

## 4. 三项结论（按要求分开写）

**① 新增 CDC 系统能力**（Baseline vs noComp/均匀）
DLC 75：两者 ey 峰值接近（0.639 vs 0.648），baseline 的方向盘与 Mz 更小；
Slalom 80：baseline `ey_max` 0.8925 明显更大、`LTR` 到 1.000。**优势不是全面的。**

**② 同网格下的补偿影响**（noComp vs Comp，同一网格）
- DLC 75：`0.6483/0.6484`（均匀）、`0.6196/0.6193`（非均匀）——**几乎完全相同**，
  即 DLC 上 `tau_d=0.01` 与 `1e-4` 无可分辨差异。
- Slalom 80：均匀 `0.7735 → 0.7432`（−3.9%）、非均匀 `0.7526 → 0.7562`（+0.5%）。
  **补偿的收益只在均匀网格下出现，非均匀网格下消失。**

**③ 同补偿设置下的网格影响**（均匀 vs 非均匀）
- noComp：DLC75 `0.6483 → 0.6196`（−4.4%）、SW `122.4 → 71.1`
- Comp：DLC75 `0.6484 → 0.6193`（−4.5%）、SW `122.4 → 71.4`
- Slalom noComp：`0.7735 → 0.7526`（−2.7%）、SW `211.5 → 152.3`，但 LTR 0.679→0.690、φ 3.80→3.92
- Slalom Comp：`0.7432 → 0.7562`（+1.7%，略差）、SW `167.6 → 142.4`、Mz `1913 → 1324`

**网格的收益不依赖补偿**（noComp 与 Comp 都拿到同量级的改善），
这不是"补偿算法"的功劳，是**预测网格**的功劳。

## 5. 口径说明

- DLC 按**里程**结束（t_end 9.94 s，200 m），Slalom 按 **8 s**；表内 RMS 为时间 RMS。
- `LTR` 由四轮 Fz 计算；**达到 1.000 表示内侧车轮卸载到零（离地），不是翻车**。
  baseline 在 Slalom 出现 27 个样本 >0.95，需要单独说明。
- SW 峰值不表征平滑性，故同时给变化率 RMS（DLC 85–113 °/s，Slalom 363–415 °/s）。
- `Mz_avg` 为平均绝对横摆力矩命令，非制动能耗。
- 墙钟仅主机仿真时间，**不代表 ECU 实时性**；本表 QP 失败 0、候选回退 0。
