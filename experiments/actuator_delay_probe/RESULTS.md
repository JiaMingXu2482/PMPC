# pmpc_mil.slx 减振器链路的时延特性（只用 MAIN 自己的实现）

数据来源：`Controller/MAIN/nlcsnn/*`（`fwd_mf_impl`、`inv_current_impl_10ms`、
`curr_dyn_impl`）与 `init_valve2.m`。**没有使用 MR_NLCSNN 的任何函数或数据。**
方法：1 ms 定步长、恒定压缩速度 `v`、`cmpD=0`、`Temp=30 °C`，对电流做阶跃，
用 `fwd_mf_impl` 算力，量 t10/t90；`tau = (t90-t10)/2.1972`。

## 1. 先看模型里到底有什么

`pmpc_mil.slx` 的 Stateflow 脚本只调用：

```
inv_current_impl_10ms, fwd_mf_impl, force_bounds_four, pmpc_preview, lon_arbitrate
```

**没有 `curr_dyn_impl`** —— 也就是说 MATLAB 侧**没有显式的电流一阶滞后块**。
模型里电流的时间效应只剩两处：

1. `inv_current_impl_10ms` 每 **10 ms** 才更新一次电流（零阶保持）；
2. `fwd_mf_impl` 用 `I_prev`（上一拍电流）作观测，且网络本身是 **GRU（2×8）**，
   带内部递归状态 —— 力对电流的响应不是纯静态映射。

真实电流环的动态（阀/线圈）在模型里**不存在**，那部分由 CarSim 的悬架模型承担。

## 2. 实测（同一链路，1 ms 步长）

| 条件 | v [mm/s] | t10 | t90 | τ_eff | F(0.4A) | F(1.2A) | 口径 |
|---|---|---|---|---|---|---|---|
| 压缩·升 | +200 | 1.0 ms | 28.0 ms | **12.3 ms** | 7270 N | 4779 N | A 模型现接法 |
| 压缩·升 | +200 | 8.0 | 36.0 | 12.7 | 同上 | 同上 | B 若接 curr_dyn |
| 压缩·降 | +200 | 1.0 | 20.0 | **8.6** | 4779 | 7270 | A |
| 压缩·降 | +200 | 1.0 | 27.0 | 11.8 | | | B |
| 复原·升 | −200 | 1.0 | 10.0 | **4.1** | −1587 | −675 | A |
| 复原·升 | −200 | 1.0 | 17.0 | 7.3 | | | B |
| 复原·降 | −200 | 1.0 | 13.0 | **5.5** | −675 | −1587 | A |
| 复原·降 | −200 | 2.0 | 26.0 | 10.9 | | | B |

A = 模型当前的实际接线；B = 假如把 `curr_dyn_impl`（τ_rise 4.55 ms / τ_fall 8.65 ms，
取自其头注释）也串进去。

## 3. 结论

1. **模型里能实现的 τ_eff 只有 4–13 ms**（A），接上 curr_dyn 也只有 7–13 ms（B）。
2. 因此：
   - DLC 用的 `tau_d = 0.01 s` 与模型的实际量级**基本吻合**；
   - **Slalom 用的 `tau_d = 0.20 s` 是模型可实现值的 16–40 倍**，
     它只能是**调参得到的等效值**，不是这个模型的性质。
3. 力对电流**没有纯延迟**（t10 ≈ 1–2 ms），延迟全部来自
   10 ms 电流保持 + GRU 内部状态（A）或再加电流一阶环节（B）。
4. 方向不对称：压缩 8.6–12.3 ms vs 复原 4.1–5.5 ms（A），约 2–3 倍。

## 4. 一个需要你注意的量级异常

本模型在 `v=+200 mm/s`、`I=0.4 A` 时给出 **7270 N**；`I=1.2 A` 时 4779 N。
（复原因方向为负、量级 675–1587 N。）
如果你手上的台架/实测数据不是这个量级，那说明**迁移到 MAIN 的正模型标定与源项目不一致**，
需要先核对 `fwd_weights_m.m` 与 `init_valve2.m`，再谈时延。
