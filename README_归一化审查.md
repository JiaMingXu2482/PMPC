## 二、结构性问题：两类分母混用

**Q 系列除以「限值」（常量）** —— 权重的含义是「离约束限值有多近」，与工况无关。
这是对的。

**R2 / S2 / S3 除以「瞬时可达值」（状态相关）** —— 权重的含义变成「用掉了当前
可用能力的多少比例」。可用能力随状态变，同一个权重数字在不同时刻、不同工况下
**代表不同的物理含义**。这是权重无法迁移的结构性原因。

正确的划分应该是：

> **约束（bounds）负责表达「此刻能做到什么」；
> 代价归一化负责表达「我们在意的尺度是多少」。**

两者混用就会重复计入。这个错误在本项目里出现了两次：

1. `R2 = CostWeights.R2/dMFxmax²`，而 `dMFxmax ∝ MFxmax`（瞬时可达值）。抬轮
   时 `MFxmax = 0` → `R2 = Inf` → H 非有限 → QP 失败。鱼钩工况 799 次求解里
   137 次（17%）因此报错，与抬轮占比 20% 吻合。已加地板 `max(dMFxmax², 1e3)`
   作为急救，但**地板只是止血，不是根治**。
2. `func_QPA_CDC.m` 的正则项 `Wd = 1/(v²+1e-2)`：各角出力上限已由 `lb/ub`
   （来自 `Gu/Gl`，本身就正比于 |v|）限死，再按速度罚一遍是重复惩罚，实测让
   分配器丢掉 20% 的请求力矩。已改为按 `span = ub−lb` 归一化并归一到均值 1。

## 三、Q2 的车速依赖

`r_ssmax = −CarHat·αr_lim·(1+lr/lf)/(m·Vel)`，所以 `1/r_ssmax² ∝ Vel²`：

| 工况 | r_ssmax | 有效权重（相对 DLC） |
|---|---|---|
| DLC 空载 100 km/h | 0.428 | 1.00× |
| 鱼钩 载170 80 km/h | 0.452 | 0.90× |
| Slalom 空载 40 km/h | 1.069 | **0.16×** |

同一个 `CostWeights.Q2`，在 slalom 上的实际效力只有 DLC 的 1/6。目前 `Q2 = 0`
所以不咬人，但要做「一套权重跑三个工况」，Q2 一旦打开就会出问题。

`r_ssmax` 作为**约束限值**是对的（后轴饱和确实随车速变），但作为**代价归一化
分母**就引入了车速依赖。两处应该用不同的量。

## 四、σ 不是决策变量，是从属量（已查实）

### 4.1 结构证据

γ（=σ）在整个 QP 里**只出现在一个地方**：`func_BuildQPConstraints.m` 的
`A_high/A_low`，即

```
umin·γ ≤ u(k) ≤ umax·γ ,   k = 1..Nc
```

其余每一条约束（`A_cons_sh`、`A_cons_env`、`A_cons_r`）的 γ 列都写死为
`zeros(·,Nr)`；系统方程里也没有 γ。代价里 γ 只有两项：

```
Nc·V·γ²  +  (γ-γ_prev)ᵀ W_dgamma (γ-γ_prev)
```

而 `CostWeights.Wdg = [0 0 0]`——**迟滞项是关着的**。于是 γ 的子问题退化成
「在满足下界的前提下最小化 `Nc·V·γ²`」，最优解闭式可写：

```
γ* = clip( max( max_{k≤Nc} |u(k)|/u_max ,  ρ_min ),  0, ρ_max )
```

γ 恒等于约束下界。它不做任何选择。

`func_BuildQPCost.m` 里那段注释其实已经说破了这件事（"最优解恒有
gamma* = max_k |u(k)|/u_max —— 它是被 u 唯一决定的从属变量"），
W_dgamma 就是为此加的解药；但解药的剂量是 0。

### 4.2 数值证据（鱼钩 PMPC，800 拍）

DB 通道可直接比对（`MFxmax`/`MFx_next` 有记录）。按 `MFxmax` 下限筛拍，
排除 `MFxmax→0` 时比值的数值噪声：

| MFxmax > | 拍数 | gap<0 | \|gap\|<1e-2 | 中位 gap | corr(ρ, \|u\|/umax) |
|---|---|---|---|---|---|
| 1 | 718 | 7.38% | 60.3% | 0.0072 | 0.402 |
| 100 | 641 | 2.18% | 67.4% | 0.0072 | 0.952 |
| **300** | **378** | **0.79%** | **83.1%** | **0.0059** | **0.986** |
| 1000 | 147 | 0.68% | 78.2% | 0.0071 | 0.996 |

`gap<0` 的拍其 `MFxmax` 中位只有 27 N·m（全局中位 320），是比值分母趋零的
噪声，不是约束被违反。中位 gap 恒为 +0.006——正号来自「视界内 k=2..6 的峰值
略高于当拍 k=1」，这仍然是跟随，只不过跟随的是视界峰值。

ρ_AFS 的分布同样说明问题：<1e-3 占 31.1%、>0.999 占 50.1%、中间只有 18.8%。
双峰，与「u 非零即饱和」一一对应。

ρ_CDC 均值 0.9888、98.2% 的时间 >0.999——被 `rho_min=[0;0;1]` 钉死。
所以 `Nc·V3·γ_CDC²` 是常数，**V3 从 10 扫到 8e4 无任何响应，至此有了确切解释**。

复现：`o = sim('cq3_2019'); diag_gamma(o)`（`diag_gamma.m` 里记了列映射，
`all` 的列号与 S-function 输出号不是连号关系，容易踩坑）。

### 4.3 这是否意味着 V1/V2/V3 没用？不是

把 γ 消去，`Nc·V·γ²` 等价于

```
Nc·V·( max_{k≤Nc} |u(k)|/u_max )²
```

即**对归一化执行器用量的「视界峰值（L∞）惩罚」**，γ 是它的 epigraph 变量。
这是完全正当的建模手法，而且 V1:V2:V3 = 100 : 8e4 : 10 确实在给三个执行器
定相对价格——AFS 便宜、DB 昂贵。机制是真的，**名字是错的**。

所以论文里的写法必须改：

- 不能写成「σ 是优先级决策变量，在线决定各执行器是否参与」；
- 应写成「σ 是执行器归一化用量峰值的 epigraph 变量，V 为其定价，实现连续的
  执行器偏好」。这样既属实，也仍然能对上 Wang 2023 的 Table I：它是**离散
  切换**（边界不连续），这里是**连续定价**。

### 4.4 若要让 σ 成为真正的决策变量

需要让 γ 在别处也出现，三条路：

1. 打开 `Wdg`（>0）。γ 获得记忆，`γ* = max(下界, W_dg·γ_prev/(Nc·V+W_dg))`，
   在切换面附近产生迟滞。代价：γ 高于下界时是非绑定的，不改变分配，只改代价。
2. 加耦合约束，如总预算 `Σγ ≤ B`——这才会逼出真正的「谁让位给谁」。
3. 让 γ 进入下层分配的权重（把 σ 传给 `func_QPA_CDC` 作为 `Gamma_d` 的缩放）。

### 4.5 已采用的解法（2026-08-31，任务 #2）

上面第 1/2/3 条都不是最好的答案。真正的问题在于**「MR 常开」被写成了
`rho_min(3)=1`，而这是把物理事实塞进了错误的位置**。

MR 是半主动件，断电仍出力，所以它的「不作用」不是 `Md=0`，而是**保持标称
电流的被动阻尼**。把 γ 的中心从 0 挪到被动工作点 `Mdnom` 即可：

```
uc + γ·(umin − uc) ≤ u ≤ uc + γ·(umax − uc),   uc = [0; 0; Mdnom]
```

AFS/DB 是主动件，`uc=0`，退化为原式。MR 的 `γ=0` 变成「保持被动阻尼」，
物理正确且始终可行，于是 `rho_min` 可以放回 `[0;0;0]`，
`Nc·V3·γ²` 不再是常数。

**实测 V3 终于响应**（鱼钩 PMPC）：

| V3 | ρ_CDC 均值 | ρ_CDC>0.999 | 制动占空 | 侧倾峰 | \|LTR\|>0.99 |
|---|---|---|---|---|---|
| 0 | 0.9830 | 97.8% | 74.7% | 6.119° | 5.63% |
| **1** | **0.9840** | **97.9%** | **71.9%** | **6.137°** | **5.63%** |
| 10 | 0.9827 | 97.4% | 73.4% | 6.233° | 5.94% |
| 1e3 | 0.9353 | 90.9% | 86.3% | 6.333° | 6.56% |
| 1e5 | 0.5540 | 31.6% | 97.2% | 7.110° | 8.44% |

给 MR 调制涨价 → 制动占空从 72% 升到 97% 去补 → 防侧翻指标同步变差。
**这条权衡曲线在修改前是完全平的**（V3 从 10 扫到 8e4 各项指标逐位相同）。

采用 `V1=100 / V2=8e4 / V3=1`，物理排序清晰：MR 最便宜（不消耗轮胎力、
不掉车速），AFS 居中，DB 最贵（掉车速 + 占纵向摩擦）。

**对 4.3 的修正**：AFS/DB 两路仍是 epigraph 从属量（`Wdg=[0 0 0]` 未开），
MR 这一路现在是真正的调制幅度决策。论文措辞按此区分描述，
不要笼统说三个执行器都在做优先级决策。

## 六、为什么这件事值得做

Wang et al., *Chassis Coordinated Control for Full X-by-Wire FWID EVs*,
IEEE TVT 72(4):4394, 2023 —— 引言里直接批评了 MPC 调权重的路线：

> "it is difficult for MPC-based methods to achieve optimal vehicle dynamics
> performance by **only adjusting the weighting coefficients** of different
> control objectives in real-time"

> （评 Ataei 的 MPC）"it is still difficult to determine the proper weighting
> coefficients for different control objectives **under varied driving
> conditions**"

该文的替代方案是规则触发（State I–V + Table I 决定哪些子系统参与）+ 分散式
事件触发滑模，验证工况正是 **slalom + DLC + fish hook** 三个。

所以「一套权重跨工况」既是这条批评的正面回答，也是与该文对比的直接抓手：
它的 Table I 是**离散切换**，边界处必然不连续；σ 是**连续**的。要把这个差异
变成论点，就得先让归一化真正起作用。
